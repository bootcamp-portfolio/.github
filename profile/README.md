# Bootcamp Portfolio

교육 과정에서 학습하고 구현한 기술 실습과 프로젝트를 정리하는 공간입니다.

## About

프로그래밍 기초부터 웹·앱 개발, 데이터 처리, AI 활용까지 학습 과정에서 만든 결과물을 저장소별로 관리합니다. 프로젝트의 목적과 구현 내용, 사용 기술을 기록해 학습 과정과 개선 사항을 돌아볼 수 있도록 합니다.

## Focus Areas

- **Application Development** — Flutter 및 모바일 앱 개발 실습
- **Web Development** — 웹 화면과 서비스 기능 구현
- **Data & AI** — 데이터 분석, 머신러닝·딥러닝 및 RAG 관련 실습
- **Learning Notes** — 교육 과정에서 작성한 코드와 실습 기록
